# MonCheptel-Back
MonCheptel est une plateforme dédiée à la gestion des exploitations d'élevage. Elle permet aux éleveurs, notamment des espèces bovines, ovines, caprines et de la volaille de d'avoir un suivi personnalisé sur leur cheptel, d'améliorer leurs production à travers des conseils pratiques, d'accéder aux soins et informations utiles 


## Code source importe

- `back/api/` : API Java.

 `LISEZ-MOI.md`, `GUIDE-ESSAI.md` et `CONTRIBUTING.md`.

Les configurations Firebase locales (`google-services.json`, `GoogleService-Info.plist`) sont exclues : les fournir separement pour activer les notifications.

Equipe : [ballasow](https://github.com/ballasow) et [Alpha-73](https://github.com/Alpha-73).
